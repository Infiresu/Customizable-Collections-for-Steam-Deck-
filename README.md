CSS Loader style for Steam Deck: allows you to customize the collection grid to your liking.
- A responsive grid that scales with your screen, featuring adjustable column counts and 3 different styles to choose from;
- A redesigned grid for game covers within collection cells, with an option to adjust corner rounding;
- Text formatting options (font size, blur effect, and horizontal/vertical alignment);
- The ability to hide the collection name and the number of games it contains;
- The option to remove the lightning bolt icon from dynamic collections.

**Note: For proper functionality, the "Collection Renamer" plugin for Decky Loader is required;**
it fixes grid performance issues that occur when dealing with long, scrollable lists.
https://github.com/Infiresu/Collection-Renamer-for-Steam-Deck-

## Installation
1. Switch to Desktop Mode and open Dolphin (explorer).
2. Unzip the style's folder to ~/homebrew/themes/.
3. Return to Gaming Mode and open Decky → CSS Loader → Refresh.
4. Enable the theme and adjust the settings.
